Informations sur les types d'annonces

  • GÉNÉRALE : Envoyée à tous les employés, annonce standard
  • DÉPARTEMENT : Envoyée uniquement aux employés du département sélectionné
  • INFORMATION : Envoyée à tous les employés, pour des informations générales
